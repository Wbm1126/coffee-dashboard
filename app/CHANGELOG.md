# 变更记录

## 1.0.1 — 2026-08-22

### 新增

- Windows x64 单文件启动器：内置 Node.js 与生产构建，双击启动并使用系统 Edge 完成 PDF 导出。
- 一键版数据独立保存在 `%LOCALAPPDATA%\CoffeeDashboard\data`，通知区域提供重新打开、打开数据目录和退出操作。
- 发行构建验证官方 Node.js SHA-256，并等待最终 EXE 自检完成后才生成发布资产。
- 同版本运行时缓存缺失关键文件时自动重建；桌面启动失败时可靠终止后台服务。

## 1.0.0 — 2026-08-15

豆迹首个正式版本。

### 新增

- 历史 Excel 双文件迁移预览、冲突确认与幂等提交。
- 历史饮用快速补录，美式与奶咖独立评价。
- 多商品购买记录、单豆饮用记录及可追溯综合评价。
- 陈列馆筛选、排序、详情、三豆比较和关注操作。
- 本地确定性个性化推荐与可解释依据。
- 用户主动触发的商品关键词搜索、URL 解析、字段确认与手工回退。
- Markdown / PDF 同快照导出。
- 记录回收站、恢复、影响预览和受约束永久删除。
- 本地 JSON 原子写入、校验备份、恢复模式和 revision 并发控制。

### 安全与隐私

- 服务仅监听 `127.0.0.1`。
- 默认离线、无账号、无遥测、无云端同步。
- 外部 URL 经过协议、端口、DNS/IP、重定向、响应大小和总截止时间校验。
- `data/`、导出文件、日志和构建产物不会进入公开 Git 仓库。

### 已知边界

- 当前为首个 `schemaVersion: 1`；未来首次升级 schema 前必须加入升级前备份与迁移回归。
- 不支持两个服务进程共享同一数据目录。
- 实时商品页面可能因站点策略或网络环境无法解析，界面会保留来源上下文并允许手工录入。
- `npm audit` 仍报告 ExcelJS 间接依赖 UUID 的 2 个中风险告警；官方给出的自动修复会降级 ExcelJS 主版本。豆迹不调用告警涉及的 UUID 缓冲区 API，v1.0 暂不采用破坏性降级，后续随 ExcelJS 上游更新处理。
